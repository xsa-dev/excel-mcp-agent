# AI-агент заявок: Excel через MCP

Учебное браузерное приложение для сотрудников компьютерного сервиса. Пользователь пишет команду обычным языком, агент определяет действие, а таблица `requests.xlsx` читается и изменяется только через MCP.

## Что реализовано

- чат с AI-агентом (Gemini API); без ключа интерфейс использует ограниченный локальный разбор демонстрационных команд, чтобы можно было увидеть MCP-цепочку;
- таблица заявок из листа `Заявки` и кнопка обновления;
- реальный журнал: пользователь → агент → MCP-инструмент → Excel-файл → результат;
- добавление заявки с подбором следующего ID и статусом `Новый`;
- изменение статуса только после явного подтверждения и повторной проверки Excel;
- список заявок по статусу;
- ошибки: несуществующая заявка не меняется, а заявка без описания проблемы не создаётся.

## Выбранный MCP-сервер

Использован готовый [@knorq/xlsx-mcp-server](https://github.com/knorq-ai/xlsx-mcp-server) — локальный MCP-сервер для `.xlsx`, работающий через stdio. Он выбран потому, что умеет читать лист (`read_sheet`), добавлять строку (`write_row`) и точечно менять ячейку (`write_cell`), то есть покрывает все операции задания.

Приложение подключается к нему как MCP-клиент через `StdioClientTransport`. На каждую операцию создаётся локальное stdio-подключение к готовому серверу; API приложения не импортирует `openpyxl`, `pandas`, `xlsx` или другую библиотеку для прямого доступа к Excel.

Используемые MCP-инструменты:

- `read_sheet` — загрузить актуальные заявки и проверить результат изменения;
- `write_row` — добавить новую заявку;
- `write_cell` — изменить статус подтверждённой заявки;
- `create_workbook` и `write_rows` — только для начального создания учебного файла командой `npm run seed`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env
```

В `.env` добавьте личный ключ Google AI Studio:

```dotenv
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-2.5-flash
PORT=3001
```

Затем создайте исходный учебный файл и запустите сайт:

```bash
npm run seed
npm start
```

Откройте `http://localhost:3001`.

`npm run seed` каждый раз заново создаёт `data/requests.xlsx` с заявками №101–103. Команда использует готовый MCP-сервер, поэтому начальная таблица также создаётся через MCP.

## Демонстрация сценариев

1. `Добавь заявку от Анны Смирновой: ноутбук сильно тормозит` — появится №104 со статусом `Новый`.
2. `Измени статус заявки Анны Смирновой на "В работе"`, затем `да` — агент сначала показывает найденную запись, затем вызывает `write_cell` и читает Excel повторно для проверки.
3. `Покажи все заявки со статусом "В работе"` — после первых двух действий будут показаны Мария Соколова и Анна Смирнова.
4. `Измени статус заявки №999 на "Готово"` — выводится ошибка, вызова `write_cell` нет.
5. `Добавь новую заявку от Дмитрия` — агент просит описание проблемы, записи не создаёт.

## Проверка

```bash
npm test
```

Тест заново создаёт книгу через MCP, вызывает `read_sheet`, `write_row`, `write_cell` и подтверждает итоговые данные. После теста выполните `npm run seed`, если нужен исходный набор №101–103.
