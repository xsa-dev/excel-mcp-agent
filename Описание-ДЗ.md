# Описание проекта

**Название:** AI-агент для заявок компьютерного сервиса.

Приложение — локальный сайт с чатом и отображением таблицы заявок. Агент получает текстовую команду, определяет нужное действие, а затем запрашивает Excel через MCP. На странице виден журнал каждого обращения: название инструмента, параметры и возвращённый результат.

**Готовый MCP-сервер:** [@knorq/xlsx-mcp-server](https://github.com/knorq-ai/xlsx-mcp-server). Это готовый локальный stdio MCP-сервер для Excel `.xlsx`; он поддерживает чтение, запись строк и изменение ячеек. Выбран, потому что все три требуемые операции доступны без создания собственного сервера.

**Подключение:** backend Node.js запускает готовый сервер как дочерний stdio-процесс через MCP TypeScript SDK и `StdioClientTransport`. Затем вызывает у него `read_sheet`, `write_row` или `write_cell`. Сам backend не читает и не редактирует `.xlsx` напрямую.

**Инструменты MCP:**

- `read_sheet` — показать актуальную таблицу, найти нужную заявку и проверить изменение;
- `write_row` — создать новую строку заявки;
- `write_cell` — изменить статус в колонке «Статус»;
- `create_workbook`, `write_rows` — создать исходный `requests.xlsx` при запуске `npm run seed`.

**AI-часть:** Gemini получает сообщение и формирует план действия: добавить заявку, предложить изменение статуса или выбрать заявки по статусу. Для изменения агент запрашивает подтверждение; пока пользователь не ответит «да», запись не выполняется.

**Проверенные сценарии:** добавление Анны Смирновой №104, подтверждённое изменение её статуса, вывод двух заявок «В работе», обработка ID №999 и команды без описания проблемы.
